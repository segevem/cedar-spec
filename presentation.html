Constructing a Relational Spec

The inductive spec must match Cedar's functional typechecker

Cedar's functional spec

def typeOf : Expr → Result …
  | .and x₁ x₂ =>
    match typeOf x₁ with
    | .bool .ff => (.bool .ff, ∅)
    | .bool b₁  =>
      match typeOf x₂ with
      | .bool b₂ => andTy b₁ b₂
      | _        => error
  | …

Our relational spec

inductive HasType : Expr → … → Prop
  | andShort :
    HasType x₁ … (.bool .ff) … →
    HasType (.and x₁ x₂) … (.bool .ff)
  | and :
    HasType x₁ … (.bool b₁) … →
    HasType x₂ … (.bool b₂) … →
    HasTypeAnd b₁ b₂ … ty … →
    HasType (.and x₁ x₂) … ty …
